# Stratorys SMI v0.1.0

First public release of the native Rust terminal hardware dashboard.

- Live CPU, memory, GPU, power, temperature and fan monitoring where supported.
- NVIDIA telemetry on Linux and native Apple silicon telemetry on macOS.
- Responsive overview, metric histories, optional sensor detail pages and plain-text snapshots with `--once`.
- Read-only local monitoring, with no daemon, network listener or CUDA toolkit required.

## Downloads

- `stratorys-smi-v0.1.0-linux-x86_64.tar.gz`: Linux x86_64, built on Ubuntu 24.04. NVIDIA monitoring requires an installed NVIDIA driver and NVML library.
- `stratorys-smi-v0.1.0-macos-arm64.tar.gz`: macOS Apple silicon, built on macOS 15. Intel Macs are not supported.
- `SHA256SUMS`: SHA-256 checksums of both archives.

Each archive contains the executable, README and MPL-2.0 license. Extract it and run `./stratorys-smi`; Rust is not required. See the README for checksum verification and installation instructions.

## Known limits

Windows is not supported. Older OS versions have not been validated. Sensor availability depends on the hardware, OS and permissions; unavailable measurements remain unavailable. Apple unified RAM is not dedicated GPU VRAM. The dashboard requires at least 60 columns, with its minimum height depending on the number of GPUs and CPU threads.

The macOS executable is not signed or notarized. Performance targets and host-specific measurements in the README are not guarantees.
